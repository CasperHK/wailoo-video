# 圍爐 (WaiLoo.video)

> **「自己友，睇好戲。」—— 香港本土獨立影像創作者與微電影聚落**

「圍爐」是一個專為香港本地創作者打造的去中心化、無演算法焦慮的影像創作與分享平台。我們反對 YouTube 式的流量內捲與大眾化娛樂霸權，回歸影像創作本身的純粹與人與人之間的真誠交流。無論你是資深獨立電影人、剪接師、編劇，還是熱愛用鏡頭記錄香港故事的素人，這裡都是屬於你的創作基地。

---

## 🌟 核心理念 (Core Philosophy)

*   **無大台、去網紅化**：打破百萬訂閱的流量霸權，每一個上載作品的創作者都是平等的「爐主」，讓好作品靠口碑發酵，而非演算法操縱。
*   **重交流而非追數據**：反對「互訂 (Sub for Sub)」與盲目追逐點擊率。評論區鼓勵針對劇本、鏡頭語言、剪接手法的深度切磋，像圍爐傾偈一樣溫暖而真誠。
*   **創作者主權**：為香港本土微電影、實驗短片、獨立MV提供一個乾淨、高質素的專屬展示空間（Portfolio）。

---

## 🚀 平台特色功能 (Platform Features)

1. **「開爐」與「圍埋嚟」 (Publish & Gather)**
   * **開爐 (Publish)**：創作者上載自己精心剪輯的微電影或短片。
   * **圍埋嚟 (Watch & Critique)**：觀眾與同行進入作品頁面觀賞，交流創作心得與技術回饋。
2. **爐主工作室 (Creator Portfolios)**
   * 取消傳統冰冷的「頻道 (Channel)」概念，改為沉浸式個人工作室展位，完整呈現創作者的風格履歷與過往作品。
3. **本地素材共創池 (Local B-roll & OST Sharing)**
   * 鼓勵香港本地創作者互相支援，共享香港街景 B-roll、獨立音樂人原創配樂（Soundtrack），降低獨立拍攝門檻。
4. **純淨無干擾觀影體驗**
   * 零煩擾廣告、無垃圾推薦，回歸純粹的視覺美學與故事享受。

## 🛠️ 技術架構與理念 (Tech Stack & Architecture)

* **高效前端**：追求極致流暢與輕量化，告別肥大臃腫的Web架構。
* **分佈式串流**：針對香港本地網絡環境優化的影音傳輸與低延遲點播。
* **開源與透明**：致力於回饋本地開發者與創作者社群。

## 📦 快速開始 (Getting Started)

如果你想參與「圍爐」的建設或了解最新進展：

```bash
# 克隆專案
git clone https://github.com/ailoo-hk/wailoo-video.git

# 進入專案資料夾
cd wailoo-video

# 安裝前端依賴（Qwik City）
cd src/frontend
bun install

# 啟動本地開發伺服器
bun run dev
```

或在專案根目錄使用快捷指令：

```bash
bun run frontend:dev
```
